# Font Files Directory

Place your font files here. The following fonts are required:

## Required Fonts

### New Icon Script
- `NewIconScript-Regular.otf` OR `NewIconScript-Regular.ttf`
- Alternative naming: `New Icon Script Regular.otf` OR `New Icon Script Regular.ttf`

### Glacial Indifference
- `GlacialIndifference-Regular.otf` OR `GlacialIndifference-Regular.ttf`
- `GlacialIndifference-Bold.otf` OR `GlacialIndifference-Bold.ttf`
- Alternative naming: `Glacial Indifference Regular.otf` OR `Glacial Indifference Regular.ttf`
- Alternative naming: `Glacial Indifference Bold.otf` OR `Glacial Indifference Bold.ttf`

## Font Locations

You can place fonts in either:
1. **This directory** (`app/fonts/`)
2. **`fonts/`** directory at project root

The code will automatically check both locations.

## Download Links

- **Glacial Indifference** (Free): https://www.fontsquirrel.com/fonts/glacial-indifference
- **New Icon Script** (Paid): Purchase from Font Bros or similar font retailers
